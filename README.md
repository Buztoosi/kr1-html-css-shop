# Учебный интернет-магазин ShopProject

## Контрольная работа №1

## Описание проекта

В рамках контрольной работы №1 разработан многостраничный HTML/CSS-сайт учебного интернет-магазина. Проект демонстрирует владение семантической HTML-разметкой, CSS-переменными, Flexbox, CSS Grid, базовым БЭМ-именованием, позиционированием элементов и публикацией через GitHub Pages.

## Обязательные страницы

### 1. Главная страница (`index.html`)
- Hero-блок с призывом к действию
- Блок преимуществ
- Популярные товары с карточками
- Модальное окно с формой заявки

### 2. Каталог (`catalog.html`)
- Сетка карточек товаров через CSS Grid
- Статический блок фильтров (sticky)
- Бейджи "Новинка", "Скидка", "Хит" (position: absolute)

### 3. Карточка товара (`product.html`)
- Изображение и описание товара
- Таблица характеристик (caption, thead, tbody, th, td)
- Хлебные крошки (самостоятельная доработка)

### 4. Форма заявки (`order.html`)
- Полноценная форма оформления заказа
- Все обязательные поля: имя, email, телефон, товар, дата, комментарий, согласие
- HTML-валидация

### 5. Контакты (`contacts.html`)
- Контактная информация (адрес, телефон, email, часы работы)
- Форма обратной связи
- Кликабельные ссылки tel: и mailto:

## Реализованные элементы

### Семантическая разметка
- `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`
- Единая навигация между всеми страницами
- Якорные ссылки (`#advantages`, `#popular`, `#contacts`)

### CSS-переменные
- Цвета: `--color-primary`, `--color-text`, `--color-bg`, `--color-danger`
- Отступы: `--space-sm`, `--space-md`, `--space-lg`
- Радиусы: `--radius-sm`, `--radius-md`, `--radius-lg`
- Тени: `--shadow-sm`, `--shadow-md`

### Состояния элементов
- `:hover` — изменение цвета кнопок и ссылок
- `:focus-visible` — видимый фокус для клавиатурной навигации
- `:active` — эффект нажатия
- `:disabled` — стили для неактивных элементов

### Flexbox
- Шапка сайта (логотип + навигация)
- Навигационное меню
- Список преимуществ
- Группа кнопок

### CSS Grid
- Сетка каталога товаров
- Раскладка страницы товара (изображение + информация)
- Раскладка страницы контактов (контакты + форма)
- Структура каталога с фильтрами

### БЭМ-именование
- Блоки: `site-header`, `site-nav`, `product-card`, `order-form`
- Элементы: `site-header__logo`, `product-card__title`, `order-form__field`
- Модификаторы: `site-nav__link--active`, `product-card--discount`

### Позиционирование
- `position: sticky` — шапка сайта и блок фильтров
- `position: relative` + `position: absolute` — бейджи на карточках
- `position: fixed` — кнопка "Наверх" (самостоятельная доработка)
- `z-index` — управление слоями (модальное окно, шапка, кнопка)
